# 拆解：Claude Fable 5 系统提示词有什么价值

> 配套文件：[中文翻译](CLAUDE-FABLE-5.zh.md) ｜ [英文原文](CLAUDE-FABLE-5.en.md)
> 联网核验日期：2026-06-15

一份前沿模型的系统提示词，不是"使用说明"，而是**一家实验室把价值观、法务红线、产品形态翻译成自然语言指令的一手样本**。它的价值不在"教你用 Claude"，而在让你看清四件事：Anthropic 在卖什么、怕什么、怎么把模型"掰"成现在这个样子、产品边界在哪。

## 0. 先验真伪（决定后面怎么读）

| 维度 | 结论 | 依据 |
|------|------|------|
| 产品线 | **属实** | Anthropic 2026-06-09 官方发布 Fable 5 / Mythos 5 |
| "产品信息"段落 | **与官方一致** | 模型 ID、双 SKU、分类器/回退、1M 上下文均对得上官方文档 |
| 提示词全文逐字 | **无法核验** | 社区诱导提取，可能截断/改写/夹带幻觉 |
| 行为是否全由它决定 | **否** | 系统提示词只是最表层方向盘，多数行为来自训练 |

所以下面的拆解，把它当作"**一份高可信、但非官方权威的近似样本**"来读——结论可信，逐字不可引。

## 1. 产品与商业策略信号（对趋势追踪最有价值）

- **双 SKU = 把"安全等级"做成产品维度**。Fable 5（带安全分类器，公开）与 Mythos 5（无分类器，仅 Project Glasswing 审批客户）共用同一底座，**差异不在能力而在约束**。这把"对齐税"反过来变成了商品：未删减的原始能力作为高价值资产，只卖给经过审查的网络防御方。这与本仓库已有 signal《Two-SKU Release Pattern》是同一条线。
- **"拒答即路由"是一种架构选择**。官方文档证实：Fable 5 触发分类器时返回 `stop_reason: "refusal"`，再 fallback 到另一 Claude 模型（如 Opus 4.8）。提示词里的 `cyber_warning` 等分类器提醒，正是这一机制在提示层的投影。**能力闸门 = 模型路由**，而非简单的"我不能回答"。
- **分层命名上移**。"Mythos-class 凌驾 Opus"意味着 Anthropic 不再用 Opus 点版本号往上叠，而是开了新层级——命名即定位。

## 2. 前沿实验室如何"操控"模型（提示工程范本）

这是对**构建者**最实用的部分——一份可借鉴的"如何掰一个前沿模型"参考。

- **拒答是判断，不是关键词黑名单**。"说得越少越安全"、武器细节"无论如何包装都拒绝"、明确禁止用"公开可得/研究意图"自我合理化——这才是真正的反越狱逻辑：靠原则与情境判断，而非正则匹配。
- **版权红线的极端写法值得研究**。全大写、反复强调、`15 词上限 / 每源一引 / 自查清单`——一段规则被重复三遍。这反向暴露了**版权/复述是头号法务风险**，也展示了"重复 + 自查清单"是它们在提示层强制执行硬约束的手段。
- **心理健康板块的颗粒度=事故驱动的微调**。不给未披露的诊断贴标签、不建议用疼痛/感官冲击做自伤替代、明确指出"NEDA 热线已停用，改用 NAED"——这种具体到机构名的指令，几乎只能来自真实事故复盘。
- **反谄媚 / 反沉迷，与"engagement 最大化"反向**。"绝不仅因对方联系你就道谢"、"不要请对方继续聊"、"不培养对 Claude 的依赖"——这是把一种价值观写死在提示里，刻意对抗社交产品的留存设计。
- **中立性是有架构的**。"呈现别人会怎么论证，而非 Claude 自己的观点"、可以拒绝就争议政治给出个人意见——一套可操作的政治中立工程，而非空泛口号。
- **格式纪律 = 反"AI 味"**。强烈反对滥用 bullet / 加粗 / 标题，要求默认散文。这是对"列表式 AI slop"的明确纠偏，也解释了为什么新模型回答读起来更像人写的。

## 3. 产品能力面（竞品 / 集成情报）

提示词等于一张**消费端产品的工具地图**：

- 全套工具：web_search / web_fetch / image_search、代码执行、文件创建、artifacts、体育数据、地点地图、天气、菜谱、消息撰写、ask_user_input。
- **artifacts 持久化 KV 存储**（`window.storage`，含 personal/shared 作用域）——artifact 从"一次性渲染"升级为可存数据的小应用。
- **Skills 系统**：动手前必须先读 `/mnt/skills/public/*/SKILL.md`——一种"环境约束外置成文档"的路由模式。
- **"Claudeception"**：artifact 内可回调 `api.anthropic.com/v1/messages` 造 AI 应用（示例里子调用固定用 Sonnet）。
- **分类器/提醒层**：`image_reminder / cyber_warning / ethics_reminder / ip_reminder / long_conversation_reminder`——揭示存在一层运行时分类器在向上下文注入告警。

## 4. 运营 / 元层细节

- **知识截止（2026-01）vs 部署（2026-06）约 5 个月差**，并附带"如何在这个时间差里得体行事"（主动搜、别提截止日期）的具体指令。
- **引用系统 `antml:cite` 的内部机制**——平时看不到的归因标记规则。
- **MCP App 推荐礼仪**："不要像销售"、第三方连接器必须 opt-in、电商绝不主动推荐——一套面向 agent 电商时代的设计哲学。

## 5. 对谁有用 / 怎么用

| 角色 | 价值 | 用法 |
|------|------|------|
| 提示工程师 / 构建者 | 操控前沿模型的范本 | 借鉴自查清单、判断式拒答、反谄媚、格式纪律的写法 |
| 趋势追踪（本仓库） | 产品与价值观策略信号 | 提炼为 signal：双 SKU、安全即产品、路由式安全闸门、agent 电商礼仪 |
| 竞品 / 集成分析 | 消费端能力面地图 | 对照自家产品查工具覆盖与安全优先级 |

## 6. 价值的边界（别过度解读）

1. **未核验逐字**——精确措辞不可作为事实引用。
2. **只是表层**——它是方向盘不是引擎；模型的真实能力与价值观主要由训练塑造，提示词只能在边缘上调。
3. **快照会变**——系统提示词更新频繁，今天看到的几周后可能已不同。

**一句话**：它最大的价值，是让你免费旁观一家头部实验室**如何用自然语言同时管理"能力、法务、价值观、产品"四件事**——产品策略看得清，提示工程学得到，但别把它当圣经。
