# 一句话核心

> **一份系统提示词搬运的是「行为」而非「能力」：把 Fable 5 的提示词贴给弱模型，能复制它的"举止"（语气、拒答边界、工具习惯），复制不了它的"智商"（推理、代码、知识）。"贴上 prompt 就变强"是 2026 年最流行的认知误区——能力来自权重，提示词只是最表层的方向盘。**

- **关键前提**：系统提示词 ≠ 模型本身。它是可调的表层，多数行为来自训练。

# 为什么这是个信号

系统提示词泄露已常态化，随之冒出一种民间叙事——"把某前沿模型的 system prompt 贴给小模型，它就能变成那个模型"。**这是认知误区，且会越来越多。** 区分"行为层（可迁移）"与"能力层（不可迁移）"这两件事，正在成为 2026 年用好模型的核心判断力：行为靠提示词塑形，能力靠 test-time compute / 蒸馏 / 路由这些工程手段补——两者代价、上限、适用任务完全不同。把它们混为一谈，要么浪费 token 堆无效提示，要么误信"小模型已对齐前沿"。

# 核心观点

| # | 观点 | 论据 | 适用判断 |
|---|------|------|---------|
| 1 | **提示词搬运行为，不搬运能力** | 推理/代码/知识来自权重；提示词只改"怎么表现"不改"有多强" | 看到"贴 prompt 变强"叙事先问：它说的是行为还是能力 |
| 2 | **行为层高 ROI 且应保留安全段** | 语气纪律、判断式拒答、版权红线、wellbeing 护栏均可迁且不损能力 | 移植时保留安全段——删它只增风险、换不来能力 |
| 3 | **推理是最难补的一块，且有硬天花板** | test-time scaling 在窄域可反超（1B 数学反超 405B），通用域收益有限 | 想要通用推理对齐前沿，最确定的仍是换底座 |
| 4 | **补能力的代价是 token/延迟/成本** | 自洽采样、Best-of-N、蒸馏 RL 全在用算力换准确率 | 上任何技术前先画"准确率 vs 成本"曲线 |
| 5 | **小模型上某些"增强"会反噬** | 多智能体辩论群体思维放大错误；无外部信号的自我反思常原地踏步 | 别无脑套用大模型的 agent 技巧到 SLM |

# 可复用框架

## 框架 A：能力可移植性光谱

```
可搬运（提示词）          ←──────────────┼──────────────→          不可搬运（权重）
语气/格式  拒答/安全姿态  中立性/反谄媚 │ 工具脚手架(需真有工具) │ 推理深度  代码  世界知识
   纯风格      行为规则       价值观     │      依赖运行环境        │   来自训练，只能换底座/外接工具补
```

判断任何"提示词迁移"主张时，先把它落在这条光谱上：越靠左越可信，越靠右越是空头支票。

## 框架 B：补推理的三条路线（按门槛）

| 路线 | 手段 | 门槛 | 天花板 |
|------|------|------|--------|
| 推理时 | CoT、自洽采样、Best-of-N+验证器、工具增强、计算-最优分配 | 低（只改 prompt+编排） | 窄域可观，通用有限 |
| 训练时 | 长 CoT 蒸馏、可验证奖励 RL、训练 PRM | 高（需微调权重） | 真正抬高上限 |
| 换底座/混合 | 难度路由 cascade、草稿—验证分工、Mixture of Opinions | 中（工程编排） | 最务实的折中 |

## 框架 C：提示词 = 方向盘，不是引擎

> 系统提示词决定模型**怎么开**（方向、风格、刹车在哪），决定不了它的**马力**（推理/知识）。想跑得更快，要么换发动机（底座），要么外挂涡轮（test-time compute / 工具）——光转方向盘没用。

# 金句

> 你能复制 Fable 5 的"举止"，复制不了它的"智商"。

> 提示词补"行为"，工程补"能力"——两者代价与上限完全不同。

> 能缩小差距，不能抹平差距；且差距越窄，账单越贵。

# 我的延展

- **对构建者的启示**：这套方法最适合"你本就在用 Opus/Sonnet，想把产品级举止补齐到 Fable 5 的感觉"，而非"把小模型变聪明"。先做行为迁移（几乎免费），再按任务上 test-time compute（按成本曲线决定）。
- **对趋势判断的启示**：系统提示词泄露 + "贴 prompt 变强"叙事会同步增长。具备"行为/能力"二分的判断力，是过滤这类噪音的关键。
- **反对意见 / 盲点**：
  - 本信号底层文本**未经官方确认**，若文本本身是伪造/拼接，"提示词揭示了什么"的部分需降权（但"行为≠能力"这个结论独立于该文本成立）。
  - "窄域可反超大模型"的研究多在**有自动验证的数学/代码**上，外推到开放任务有风险。
  - 训练时路线（蒸馏/RL）严格说已超出"用提示词"范畴——若读者只能改 prompt，框架 B 的上半部分对其无效，需诚实告知。
  - 随模型迭代，部分"补能力"技巧可能被底座原生能力吸收（如 adaptive thinking 内化了 CoT），手册有时效性。
