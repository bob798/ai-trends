# ai-trends

**追踪 AI 行业的信号，不是新闻。**

这里不是博客，也不是新闻聚合器。这里是一个个人维护的**信号库**：每条记录都对应一份原始材料（播客、论文、产品发布、深度访谈），经过结构化拆解，目的是让我（以及读到的人）能更快地看出趋势的形状。

## 这里有什么

- **`signals/`** — 单点信号。一份原始材料 = 一篇拆解。结构固定：核心观点 / 论据 / 框架 / 延展。
- **`themes/`**（未来） — 当某个主题积累到 5 条以上信号时，会拉一份主题聚合，对比、追踪、推演。
- **`_template-signal.md`** — 信号模板。

## 我怎么筛选

只记录满足以下至少一条的内容：

1. **结构性观察**：揭示了某种商业模式、技术路径、组织形态的拐点
2. **可证伪的预测**：给出了具体时间窗口或量化目标
3. **反共识但有论据**：与主流叙事相反，且作者拿得出第一手证据
4. **可复用框架**：能迁移到其他场景的思考模型

新闻、产品宣传、空泛预测——不记。

## 信号强度

每条信号会标 `signal_strength: weak | medium | strong`：

- **strong** — 来自第一手实践者，包含可验证数据或反共识洞察
- **medium** — 高质量分析，但论据偏经验/未量化
- **weak** — 值得留档但需要更多证据支撑
